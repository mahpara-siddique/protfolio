Research Projects

MS-LANet v2: Multi-Head Self-Attention & Ensemble

Designed MS-LANet v2 to solve localized sorting signal dilution in 10-class protein subcellular localization by coupling a learnable-query Multi-Head Self-Attention pooling probe with frozen ESM-2 (650M) embeddings and consensus SVM ensembling.

Acc: 84.47% MCC: 0.8142 +2.67% over ESM-2 15B
PyTorch ESM-2 (650M) Self-Attn Pooling SVM Consensus
GitHub Live Demo
🧫

AMP-MHSA: Bio-Informed Attention for AMP Discovery

Engineered AMP-MHSA to overcome helical periodicity loss in antimicrobial peptide identification (AMP Scanner v2, N=2,848) using 3.6-residue Helical Positional Encodings, Eisenberg Hydrophobic Moment, and a ~449-param Bio-Attention Bias.

Acc: 93.68% MCC: 0.8745 AUROC: 0.9813
Transformers ESM-2 (650M) Helical PE (3.6) Bio-Attention Bias
GitHub Live Demo
⚗️

PROTAC-Degrade3D: 3D-EGNN & Ubiquitination Engine

Developed PROTAC-Degrade3D to predict ternary complex degradation efficacy (PROTAC-DB, N=2,832) by coupling Satorras 3D-Equivariant GNNs with a novel Ubiquitination Geometry Module (UGM) for Lysine accessibility mapping.

Acc: 97.46% MCC: 0.9444 AUROC: 0.9934
3D-EGNN UGM ESM-2 RDKit 3Dmol.js
